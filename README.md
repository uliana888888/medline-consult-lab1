# Лабораторна робота № 1 — Розмітка елементу інтерфейсу засобами HTML

**Виконала:** Шлапа Уляна (група ІПЗ-33)  
**Варіант:** 8 — Веб-ресурс з надання он-лайн консультацій лікаря («MedLine Consult»)  

## Структура проєкту
- `index.html` — Головна сторінка центру онлайн-консультацій лікарів.
- `services.html` — Сторінка «Послуги» з переліком консультацій, описом та вартістю.
- `feedback.html` — Сторінка «Зворотній зв'язок» із групованою формою звернення.
